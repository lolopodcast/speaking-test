教師工具Teacher console ・ Adaptive Speaking Test

通行碼 Admin token

輸入 Worker 設定的 ADMIN_TOKEN。只存在這個分頁，關閉即清除。

1. 產生學期代碼 Semester codes

每行貼一位學生（例如「學號 姓名」）。姓名只留在您的電腦裡，伺服器只收到代碼。

2. 考試時段 Test window

以您電腦的時區輸入。時段外學生無法開始測驗；3 次機會都要在同一時段內用完。

3. 測驗紀錄 Records

伺服器上的紀錄是最可靠的成績來源。「計分」欄標示每位學生最後一次完成的場次。

4. 驗證學生上傳的 CSV Verify

從 Moodle 下載學生的 CSV，一次選多個檔案。系統會檢查簽章是否吻合、是否為該生最後一次。
